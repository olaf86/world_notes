# App Store Connect metadata and screenshots

This is the paste-ready metadata for the first iOS release. The five App Store
Connect localizations are Japanese, English (U.S.), Korean, Simplified Chinese,
and Traditional Chinese.

## Where each field is entered

### App Information

Open **My Apps → World Notes → App Information**, then add or select each
localization under **Localizable Information**.

- Name: 30 characters maximum.
- Subtitle: 30 characters maximum.
- Privacy Policy URL: required for iOS.

### iOS App version

Open **My Apps → World Notes → App Store → iOS App → 1.0 Prepare for
Submission**, then select each language from the localization menu.

- Screenshots: 1–10 per device class and localization.
- Promotional Text: 170 characters maximum.
- Description: 4,000 characters maximum, plain text only.
- Keywords: 100 UTF-8 bytes maximum; comma-separated without spaces.
- Support URL: required and must lead to contact information.
- Marketing URL: optional.

## Shared settings

- Primary Category: **Lifestyle**
- Secondary Category: **Travel**
- Version: `1.0.0`
- Copyright: `2026 <legal person or entity name>`
- Privacy Policy URL: **Not ready.** Publish a real page before submission,
  for example `https://worldnotes.asobo.dev/privacy`.
- Support URL: **Not ready.** Publish a page containing real contact
  information before submission, for example
  `https://worldnotes.asobo.dev/support`.
- Marketing URL: leave blank for the first submission unless a product page is
  published. The current site root is an invitation fallback page and should
  not be used as the marketing page.

Do not paste either example URL until the corresponding page is publicly
available.

## Screenshot upload set

Upload the following six portrait screenshots in this order for every
localization:

1. Map (`01_map`)
2. Nearby notes list (`02_nearby_notes`)
3. Note detail and messages (`03_note_detail`)
4. My Notes (`04_my_notes`)
5. Profile (`05_profile`)
6. World Notes PRO (`06_pro`)

The iOS target supports both iPhone and iPad (`TARGETED_DEVICE_FAMILY = 1,2`),
so provide both sets:

- iPhone 6.9-inch: 1320 × 2868 PNG, no alpha channel.
- iPad 13-inch: 2064 × 2752 PNG, no alpha channel.

Maestro output directories:

```text
artifacts/store_screenshots/ios/{locale}/
artifacts/store_screenshots/ios_ipad/{locale}/
```
